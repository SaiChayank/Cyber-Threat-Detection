# Downloaded DNS archive qualification protocol

17 October 2026; baseline `b5ad602`. Frozen before inspecting ZIP catalogues,
bundled member contents or capture headers. The two producer descriptions and
previously downloaded source documentation are already exposed research material.
This task qualifies inputs only; no reserved observations or detector outcomes.

## Exact inputs and preserved gate

Use only the two original ZIPs pinned by `data/dns_public_acquisition.json`.
Recheck their whole-file SHA256 and size before member access; preserve both
originals byte-for-byte. Reuse their reviewed CC BY 4.0 rights/producer attribution.
No remote requests, new software, traffic generation or source conversions.

The frozen `data/dns_tunnel_evaluation_contract.json` remains unchanged:
>=20 independent positive and >=50 benign sessions; dnscat2 or iodine;
CDN/cloud, telemetry, service discovery, legitimate TXT and machine-generated
hostname controls; recall >=80%, precision >=95%, FPR <=2%; every TP before
completion, >=90% of TPs by query 10 AND within 10 seconds. Related runs/exports
must stay grouped. Existing source pins, runtime settings and failed candidate
remain untouched. No model fitting, prediction, tuning or scorer invocation.

## Staged inspection, before any query/packet values

1. Save complete ZIP central-directory catalogues (at most 10,000 entries each):
   original name/index, compression, sizes, CRC, flags and attributes. Names,
   extension counts and ZIP directory timestamps are metadata, never packet times,
   session counts, malicious/benign truth or independent group assignments.
2. Select only README/LICENCE/LICENSE text and explicitly named run/session
   manifest/annotation documents in JSON/YAML/TXT. Skip `__MACOSX`, `._` entries,
   binary models, source scripts, arbitrary logs, CSV/Parquet/JSONL rows and unknown
   formats. At most ten documents, <=256 KiB each and <=1 MiB total. Save a fixed
   member-selection manifest before reading. If a document contains example query
   names, record that exposure; do not later call those examples untouched tests.
   A label file is not automatically trustworthy; join it to executed run identity,
   original bounds, source/namespace and process intent independent of predictions.
3. If outer catalogues contain nested ZIPs, copy at most two, lexicographic order,
   <=600 MiB uncompressed each and <=1 GiB total, to fixed ignored workspace paths.
   Pin the selected member indices/sizes/CRC before streaming opaque container
   bytes. Verify copied size/CRC and SHA256. Inspect only one additional ZIP level
   by the same catalogue/document rules; do not descend recursively or unpack data.
4. For every nominal `.pcap`/`.pcapng` member (<=200), save a deterministic header
   selection first. Read exactly the first four bytes. PCAPNG magic establishes
   unsupported container only: stop there, no interface/packet-block parsing.
   For classic PCAP magic only, read up to the complete 24-byte global header and
   check existing reader requirements (v2.4, linktype1, valid snaplen). No packet
   record header, capture timestamp, DNS question, payload, fingerprint or feature
   is read. Do not infer format from extension or fix mismatches by conversion.
5. If labels/time/field prerequisites remain absent, stop. Full QNAME/QTYPE,
   original event timing, session counts, record-type/rate coverage and cross-role
   overlap remain unverified; do not inspect values merely to seek a passing set.

No `extractall`, upstream script/model execution, arbitrary member paths/URLs or
archive repair. Fixed local paths stay in this task's ignored metadata workspace.
No new capture reader or PCAPNG support. New byte/header inspection is documented
separately from the historical no-member-inspection acquisition report.

## Output and stop condition

Record catalogue counts, supported/unsupported headers, reviewed annotation/docs,
missing requirements and exposure. Assign training/validation/reserved roles only
if independent provenance, complete compatible original inputs, required coverage,
whole-run grouping and prior-exposure exclusions are proven before values.
Otherwise retain both sources as unqualified research intake and leave roles null.
Filenames such as train/test or numbered captures do not constitute our split.

Save protected-file before/after integrity and reproducible evidence. Documentation
and metadata-only helper changes may be made; no backend/frontend behavior changes.
Add exact unit tests if a new reusable diagnostic helper is needed or a bug is fixed.
Stop after an explicit qualification decision; no automatic evaluation/promotion.
