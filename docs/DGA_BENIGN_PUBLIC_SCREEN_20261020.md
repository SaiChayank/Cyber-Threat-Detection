## Source decisions

**Brno/CESNET domain intelligence:** the
[producer paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC12495040/) identifies the
CESNET list as TLS-SNI-derived, with recurrence/VirusTotal filtering and removal
of selected institutional subdomains. It is not an original DNS client-query
log. The open CC BY 4.0 catalogue request for concept `13330073` resolves to
version DOI `10.5281/zenodo.14332167`; its metadata advertises a 6,437,047,412-byte
CESNET JSON. No JSON rows were acquired. **Not qualified for the independent DNS
role**; machine-generated/CDN service strata are not established by SNI or
reputation membership. Source enrichment cannot become runtime lexical features.
The actual pinned version is recorded, rather than treating the concept ID as
an immutable file version.

**User DNS fingerprint:** the
[producer paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11033155/) describes a real
ISP BIND-query origin, raw-name and hashed variants, daily/hourly aggregation and
content categories. The categories include botnet/phishing/malware-related classes;
the general statement about malicious content does not certify every original
query as benign. The
[open CC BY 4.0 record](https://zenodo.org/records/10887463) advertises one
420,772,624-byte ZIP, publisher MD5 `8001d345487b0819b779ebef2279f855`.
**Not qualified as an all-benign DNS reference.** No independently clean
client/session cohort or required service categories are established here. Do
not turn aggregated content-category membership or a numeric hash into benign
query truth; no ZIP, mapping or CSV values were downloaded.

**UFU Do53/DoH:** the
[producer repository](https://github.com/CborgesUFU/DNS-360-Dataset/tree/1b3e59ffc3d14f41ccbf143be155cf791eb5e7ae)
documents controlled benign DNS resolution, Tranco targets and separately
generated attack scenarios. Its pinned licence covers data/captures with CC
BY-NC 4.0. This is a **possible Do53 follow-up lead, not a qualified reserve**:
published archive metadata exposes 34 Do53 multipart 7z files totalling
880,360,679 bytes, but does not establish actual native capture headers, member
run mapping, eligible first-label counts or required machine/CDN categories.
DoH names are unavailable passively inside TLS and are outside this lexical
DNS role. No archive, generator, source-code dependency or upstream model was
downloaded/executed. A generic recommended filename is not actual run proof.
