# Brief traceability (1 November 2026)

Each item of the official project description (`docs/Cyber Threats -Unidirectional IP Traffic.docx`, PS26145, NTRO)
mapped to what is built and what evidence exists. "Real" means a public real capture, "synthetic" means generated or
controlled cases. Numbers are from [Current status](CURRENT_STATUS.md) and [Real capture results](REAL_CAPTURE_RESULTS.md).

| Constraint | Status |
| --- | --- |
| 5.1 Read-only ingest, no return path | Tests forbid outbound sockets in the pipeline and live collector |
| 5.2 No payload decryption | Metadata only; no decryption code |

## 6-7. Inputs and data

PCAP, PCAPNG, NetFlow v5/v9, IPFIX and sFlow (files and a receive-only collector), plus JSONL metadata.
Synthetic and lab-style traffic is the training source; public real captures (CTU-13, IoT-23, CIC DNS, Burgos,
dnscat2, Ulm SUEE1) are used for measurement ([Datasets](DATASETS.md)). No attack traffic was generated by this project.

## Live end-to-end check (1 November 2026)

Production build served with a disposable database: health OK, demo replay of 256 events produced 13 alerts in all
seven classes (2 DDoS, 2 C2, 2 DGA, 2 tunnelling, 2 encrypted malware, 2 exfiltration, 1 reconnaissance), processing
p95 0.96 ms, replay status complete, dashboard `/monitor` served HTTP 200. Demo preflight (`python -m replay.demo_pack`)
passes. Full test suite: 885 passed locally, 856 passed with 4 skipped in a fresh clone.

## What is not complete, and why

- **No real-capture measurement:** slow-read, exfiltration, encrypted malware, UDP amplification. No open, labelled,
  directly downloadable capture was found ([thirteenth step](REAL_CAPTURE_RESULTS.md)).
- **Weak on real data:** DGA recall about 6%; slow-HTTP missed on SUEE1; jittered or rotating beacons; floods under
  1,000 packets per second.
- **By design:** scores are uncalibrated heuristics; single local worker, no authentication; classic and PCAPNG Ethernet
  only; no raw QUIC JA4; exfiltration intent cannot be shown from traffic.

The deliverable is a functionally complete, tested prototype meeting every item of the brief's expected solution and
constraints. It is not a field-validated classifier.
